# ATM Banking Management System

A desktop-based ATM Banking Management System developed using Java Swing, MySQL, and JDBC. The project simulates real-world ATM functionalities including secure login authentication, balance enquiry, cash deposit, withdrawal, fast cash service, mini statement generation, and PIN change.

## Features

* User Login Authentication
* Balance Enquiry
* Cash Deposit
* Cash Withdrawal
* Fast Cash Service
* PIN Change
* Mini Statement
* Transaction Management

## Tech Stack

* Java
* Java Swing
* JDBC
* MySQL

## Database

The project uses MySQL database for managing:

* User Details
* Account Information
* Login Credentials
* Transaction Records

## Project Objective

The objective of this project is to understand banking workflows, GUI development, database connectivity, and transaction handling using Java and MySQL.
